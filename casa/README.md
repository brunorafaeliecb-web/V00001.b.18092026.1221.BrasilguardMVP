# BrasilGuarD

Marco: `V.0001.b`

CRM de WhatsApp para corretores de plano de saúde. Mensagens + ficha + quadro. Nada se apaga no rastreio.

## Entrar

Primeiro cadastro vira administrador. Convite entra no papel combinado (operador, supervisor, administrador).

## Stack

TanStack Start · Postgres · Better Auth · Vercel

## Local

```bash
npm install
npm run dev
```

Não crie `.env` com segredo. `DATABASE_URL` entra no deploy.
