# Nomenclatura de rastreio

Nascido: 18.09.2026 11.32  
Papel: V.0001.a.18.09.2026.11.32.nomenclatura  
Produto: BrasilGuarD

## Forma

```
V.{versao}.{letra}.{dd}.{mm}.{aaaa}.{hh}.{mm}.{nome}
```

Exemplo: `V.0001.a.18.09.2026.11.32.nomenclatura`

| Parte | O que é | Exemplo |
|---|---|---|
| V | sempre V | V |
| versao | marco do produto, quatro dígitos | 0001 |
| letra | atualização desse marco | a, depois b, c… |
| dd.mm.aaaa.hh.mm | instante em que o papel nasceu | 18.09.2026.11.32 |
| nome | o que o papel é e permanece | nomenclatura, visao, mvp, BrasilGuarD |

## Regras

1. Nenhum papel se edita.
2. Nenhum papel se apaga.
3. Errar ou mudar de ideia: nasce um papel novo. Sobe a letra (a→b) no mesmo marco, ou sobe a versão (0001→0002) se o marco mudou.
4. A data do papel antigo não se mexe. A data nova é a hora do papel novo.
5. O nome permanece. O que muda é versão, letra e instante.
6. Quem lê o rastreio vê a história. O vigente de um nome é o de maior versão, depois maior letra, depois instante mais recente.

## Por quê

Código comentado não prova o que foi decidido. Papel com data prova. Auditoria, LGPD e segunda-feira pedem o mesmo: o que era, quando, quem mandou.
